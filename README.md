# Organizador de Arquivos

Projeto feito em Python utilizando bibliotecas shutil e os para organização de arquivos com o intuito de praticar métodos de organização de arquivos.

---
## 📚 Aprendizados
- Uso das bibliotecas shutil e os
- Uso de funções específicas para manipulação de arquivos

## ⚙️ Funcionalidades
O arquivo "organise" tem como funcionalidade:
- Organizar os arquivos de "pasta-template" em "arquivo-organizado" por tipo de arquivo (".gif", ".png", ".jgp", ".jfif", ".webp" ou ".jpeg")
